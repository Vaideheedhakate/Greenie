# 🌿 Greenie - Plant Nursery Homepage
Greenie is a responsive front-end web project designed as a plant nursery homepage. The layout is inspired by the Amazon home page structure and modified to create a clean, modern, and user-friendly nursery website interface.

## ✨ Features
* Responsive homepage layout
* Modern UI design for a plant nursery website
* Clean navigation bar and product-style sections
* Fully built using pure HTML and CSS

## 🛠️ Tech Stack
* HTML5
* CSS3

## 🎯 Project Objective
To practice front-end development skills by redesigning a popular e-commerce style layout into a themed plant nursery website.

## 💡 Learning Outcome
* Improved HTML page structuring
* Better CSS styling and layout creation
* Understanding real-world website layout replication
